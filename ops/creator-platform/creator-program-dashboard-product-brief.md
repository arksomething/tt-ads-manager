# GoTall Creator Program & Dashboard System

## 1. Overview

The goal is to create a complete **GoTall Creator Program platform**.

Creators who become interested in the program—whether through Joseph, Discord groups, referrals, or any other source—will be directed to the platform.

The system should handle the entire creator journey:

**Discover → Apply → Onboard → Set Up Accounts → Get Verified → Access Scripts → Submit Content → Track Earnings**

There will be two sides:

1. **Creator Dashboard** — for creators participating in the program.
2. **Admin Dashboard** — for managing creators, performance, content, views, and revenue.

### Step 1: Warm-Up Guide

# 5. Campaign Social Accounts

The next onboarding step is creating campaign accounts.

## Make Your Campaign Accounts

Creators need **two fresh accounts** specifically for the campaign:

- One TikTok account
- One Instagram account

They will later link and verify these accounts through the dashboard.

---

### Rule 1: Create Brand-New Accounts

Creators should not use personal accounts.

Each campaign should have dedicated accounts.

**Why:** Fresh accounts allow the algorithm to learn the content niche and audience from the beginning.

---

### Rule 2: Follow the Account Requirements

The system should clearly display the campaign's required account setup.

For example:

- Required email or phone setup
- Approved email providers
- Required target market or location
- Other campaign-specific requirements

These requirements should be clearly explained during onboarding.

---

### Rule 3: Choose a Natural Handle

Creators should use:

**Real first name + what they're doing**

Examples:

- `bens.building.things`
- `jose.does.ecom`
- `sara.tries.ecom`

Avoid:

- Brand-like usernames
- "Official"
- Random numbers
- Spam-looking usernames

---

### Rule 4: Add a Profile Picture

Creators should use:

- A clear photo of themselves, or
- A clean graphic

The same profile picture can be used across both platforms.

Avoid leaving the account with a default profile picture.

---

# 6. Account Verification

Once creators create their social accounts, they need to verify ownership.

### Verification Process

1. The system generates a unique verification code.
2. The creator adds the code to their social media bio.
3. The system checks the account.
4. Once confirmed, the account is marked as **Verified**.

The creator should verify:

- TikTok
- Instagram

Once both are verified, they can move forward.

---

# 7. Agreement

Before fully joining the program, creators should review and sign the creator agreement.

The dashboard should show:

- Agreement status
- Date signed
- Any required updates

Once signed, the creator completes onboarding and gains full access to the program.

# PART 3: Admin Dashboard

The admin dashboard is designed to manage the entire creator program.

---

# 8. Home Dashboard

The main dashboard should provide a quick overview of the program's performance.

### Date Filters

Users should be able to view:

- Today
- Last 7 days
- Last 30 days
- Custom date range

---

### Key Metrics

The home dashboard should show:

- Total views generated
- Total posts published
- Creators posted vs. total creators
- Top-performing post
- Overall performance trends
- Top creator of the selected period
- Top movers and fastest-growing creators

The goal is to quickly understand:

**How much content was posted, how many creators were active, and how the program is performing.**

---

# 9. Calendar

The Calendar provides a visual overview of creator activity.

### Each Creator Has Their Own Section

Each creator's row shows their performance across different dates.

The date columns show each day.

Each cell represents content activity and performance for that day.

---

### Color System

🟢 **Green** — Posted and performed well

🟡 **Yellow** — Posted but received low views

🔴 **Red with ❌** — Missed the required post

⚫ **Dark/Gray** — Not posted yet

🔵 **Blue** — Creator joined

🟣 **Purple** — Creator is in Discord but has not created a dashboard account

---

### Multiple Posts

If a creator posts multiple times in one day, the cell should be divided.

Each section represents an individual post and its performance.

---

### Creator Information

The left side of the calendar should show:

- Creator name
- Tier
- Group
- Daily check-ins

Daily check-ins may include:

- Today filmed
- Posted 1 of 2
- Posted 2 of 2
- Tomorrow filmed

### Purpose

The Calendar should make it easy to immediately see:

- Who posted
- Who missed a post
- Who needs a reminder
- How each post performed

---

# 10. Daily Breakdown

The Daily Breakdown provides an overall summary of the creator program for a specific day.

### Main Progress Metric

Example:

## 12/33

This shows how many required posts or creators have completed their posting requirements out of the total expected.

For example:

- **12 completed**
- **33 expected**
- **21 need a reminder or follow-up**

---

### Daily Metrics

The dashboard should show:

**Total Views**

The total views generated by posts from that day.

**Views Gained**

The additional views generated since the previous refresh.

**Performance vs. Previous Day**

Shows whether performance increased or decreased compared to the previous day.

**Last Refresh**

Displays when the dashboard was last updated.

---

### Actions

The page should include:

- **Overview** — General daily statistics
- **Discord Sends** — View reminders or messages sent
- **Preview Digest** — Preview the daily summary
- **Refresh + Send Discord** — Update data and send reminders
- **Previous / Next / Today** — Navigate between dates

### Purpose

This page allows the team to quickly understand:

**Who posted, who needs a reminder, and how many views the creator team generated.**

---

The admin dashboard should have a dedicated **Scripts** page.

The team can:

- Create new scripts
- Edit scripts
- Organize scripts
- Assign scripts to creators or groups
- Add instructions and examples

Any scripts added here should automatically become available in the appropriate creator dashboards.

# 13. Revenue & Performance Tracking

There should be a dedicated analytics section for tracking business performance.

### Track:

- Daily views
- Total views
- Revenue generated
- Revenue by day
- Revenue by creator
- Revenue by content format
- Best-performing formats
- Best-performing scripts

The purpose is to understand:

> **Which creators, scripts, and content formats are generating the best results and revenue.**
> 

This data should help the team make better decisions about where to focus.
